DEEP LEARNING · EXPLAINABILITY

Personal project · Experimental prototype

Brain Tumor MRI Classifier

A binary MRI classification prototype using a pretrained ResNet18, with Grad-CAM heatmaps and a Streamlit interface to inspect predictions.

  • PyTorch
  • Grad-CAM
  • Streamlit
  • Transfer learning
Inside the project +

The checked implementation uses two labels (tumor / no tumor), a pretrained ResNet18, and a random 80/20 image-level split. Grad-CAM helps inspect the image regions influencing a prediction.

The Streamlit interface loads the trained model for inference. The current training script does not report held-out validation metrics or enforce a patient-level split, so no accuracy claim is presented here. This is an experimental project, not a clinically validated diagnostic tool.
